# Runbook: meeting room AV quick reference

Audience: everyone.
Last reviewed: 2025-10.

## Booking

Rooms are booked through the calendar system by inviting the room as a resource.
Recurring bookings longer than 3 months are pruned quarterly.

## Using the AV

- Tap the room panel to start the scheduled meeting.
- Use the USB-C cable on the table for laptop screen sharing.
- The wireless sharing dongle is a fallback and adds about a second of latency.

## Common problems

If the panel shows the room as offline, power cycle it from the switch under the table.
If audio echoes, make sure only the room system has its microphone unmuted.
Report persistent issues to office ops with the room name and time.
