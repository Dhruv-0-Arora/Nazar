# Runbook: exam room displays

Audience: reception and IT.
Last reviewed: 2025-10.

## Layout

Each exam room has a wall display driven by a small form factor PC on the clinical VLAN.
Displays show the room schedule and are read-only.

## Common issues

- Blank display: check the PC is powered before assuming the panel failed.
- Wrong room schedule: the room mapping is set per PC; IT corrects it in the display console.
- Stale schedule: displays refresh every five minutes, so allow a full cycle before escalating.
